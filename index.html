Gemini API Key

Paste API key dari Google AI Studio (aistudio.google.com) di sini. Gratis, tidak butuh kartu kredit. Ini dipakai sebagai OCR utama.

Anthropic API Key (cadangan)

Paste API key dari console.anthropic.com di sini. Dipakai otomatis sebagai cadangan kalau Gemini kena limit/gagal setelah beberapa kali coba.

Koneksi Database (Supabase)

Paste "Project URL" dan "anon public" key dari Supabase (Project Settings → API) untuk menyimpan data bersama semua operator.

Backup Settings

Simpan semua API key & koneksi database sebagai 1 kode teks -- taruh di Notes HP atau tempat aman lainnya. Kalau suatu saat Settings ini hilang (misal browser di-reset), tinggal paste kode ini untuk isi ulang dengan cepat, tidak perlu cari-cari lagi satu-satu.
